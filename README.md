# 🎪 UHEEVERSE

> 지역 축제를 온라인에서 직접 탐험하고 체험하는  
> **Unity 기반 실감형 인터랙티브 문화 콘텐츠**

UHEEVERSE(유희버스)는 대한민국의 다양한 지역 축제를
가상의 3D 공간에서 체험할 수 있도록 제작한 프로젝트입니다.

사용자는 자신만의 캐릭터로 축제 공간을 탐험하며
NPC와의 대화, 퀘스트, 미니게임, 마이부스 꾸미기 등을 즐길 수 있습니다.

또한 실제 지역의 지형과 날씨를 콘텐츠에 반영하고,
멀티플레이와 스마트폰 조이패드를 통해
친구들과 함께 축제를 체험할 수 있도록 구현했습니다.

---

## 📌 프로젝트 개요

기존의 지역 축제 홍보가 정보 제공 중심이라는 점에서 출발하여,
사용자가 직접 축제 공간을 돌아다니고 콘텐츠에 참여하면서
자연스럽게 지역과 축제에 대해 알아갈 수 있는 서비스를 기획했습니다.

물리적인 거리와 관계없이 지역 축제를 경험할 수 있도록 하고,
게임을 통해 실제 지역 문화와 관광에 대한 관심으로 이어지는 것을 목표로 합니다.

### 개발 기간

`2025.04.01 ~ 2025.10.31`

### 팀 구성

`4인 팀 프로젝트`

---

## 🎮 주요 콘텐츠 흐름

### 1. 로그인 및 캐릭터

사용자는 로그인 후 자신의 캐릭터 정보와
커스터마이징 데이터를 불러와 게임에 접속합니다.

### 2. My Station

사용자 개인 공간이자 축제로 출발하기 위한 허브 공간입니다.

- 캐릭터 및 공간 커스터마이징
- 아이템 구매 및 인벤토리
- 마이부스 꾸미기
- 친구 초대
- 축제 선택 및 출발

### 3. Train

축제장으로 이동하는 과정을 열차 콘텐츠로 구성했습니다.

열차 내부에서는 축제가 열리는 지역과 관련된
OX 퀴즈를 풀 수 있으며,
퀴즈를 통해 획득한 코인은 이후 아이템 구매 등에 사용할 수 있습니다.

### 4. Festival

실제 지역의 지형을 기반으로 제작된 축제 공간입니다.

사용자는 축제장을 자유롭게 탐험하면서

- NPC와 대화
- 퀘스트 수행
- 미니게임
- 다른 사용자와 상호작용
- 지역 및 축제 정보 확인

등의 콘텐츠를 이용할 수 있습니다.

# ✨ 주요 기능

## 🌏 OSM 기반 축제 맵

OpenStreetMap 데이터를 활용해
실제 축제가 개최되는 지역의 지형을 Unity 공간에 구현했습니다.

Overpass를 통해 가져온 OSM 데이터를 JSON으로 변환하고,
Unity에서 데이터를 파싱하여 실제 위도·경도를 Unity 좌표로 변환합니다.

건물, 도로, 상점, 학교, 공원, 나무, 하천 등의 데이터를
태그에 따라 구분하고 Prefab을 자동으로 배치하여
지역별 축제 맵을 구성했습니다.

---

## 🌦 실시간 날씨 연동

OpenWeather API를 활용해
축제가 열리는 지역의 실제 날씨 정보를 게임에 반영합니다.

지역의 기상 정보에 따라

- 비
- 눈
- 구름

등의 시각 효과를 적용하여
실제 지역 환경과 연결된 축제 공간을 구성했습니다.

---

## 🤖 LLM 기반 NPC

축제장 NPC와의 대화 및 지역 관련 퀴즈에
LLM을 활용했습니다.

초기에는 LLM이 직접 답변을 생성하는 방식을 사용했지만,
사실과 다른 정보를 생성할 가능성을 줄이기 위해

`규칙 기반 검색 + Database + LLM`

을 결합한 하이브리드 구조로 개선했습니다.

사용자의 질문에서 축제명과 정보 유형을 분석하고,
데이터베이스에서 관련 정보를 검색한 뒤
LLM이 자연스러운 형태의 응답을 생성하도록 구성했습니다.

---

## 👥 실시간 멀티플레이

FishNet을 활용해
여러 사용자가 하나의 축제 공간에서 함께 활동할 수 있는
멀티플레이 환경을 구현했습니다.

- 플레이어 및 Network Object Spawn
- 클라이언트 간 데이터 동기화
- 개인 Scene / 공용 Scene 관리
- 실시간 채팅
- 친구 추가 및 초대
- 멀티플레이 미니게임

Scene Loading은 서버에서 관리하도록 중앙화하여
클라이언트별 독립 공간과 여러 사용자가 함께 사용하는 공간을
모두 지원하도록 구성했습니다.

---

## 📱 스마트폰 조이패드

별도의 게임 컨트롤러 없이
사용자의 스마트폰을 입력 장치로 활용할 수 있도록 구현했습니다.

스마트폰에서 발생한 입력을 PC의 Unity 클라이언트로 전달하여
캐릭터 이동과 콘텐츠 조작에 사용할 수 있습니다.

이를 통해 별도의 하드웨어 구매 없이
스마트폰만으로 게임을 조작할 수 있도록 접근성을 높였습니다.

---

## 🏠 My Booth

축제를 체험하며 획득한 아이템으로
사용자의 개인 공간을 꾸밀 수 있습니다.

아이템을 선택하면 배치 전 Ghost 형태의 Preview를 제공하며,

- 위치 조정
- 충돌 검사
- 90° 회전
- 배치
- 배치 취소

등의 기능을 지원합니다.

---

## 👕 캐릭터 커스터마이징

의상과 헤어 등의 요소를 Prefab 단위로 관리하여
사용자가 자신의 캐릭터를 꾸밀 수 있도록 구현했습니다.

캐릭터의 Bone 구조와
각 의상의 `SkinnedMeshRenderer`를 동기화하여
교체된 의상에서도 캐릭터 애니메이션과 물리 효과가
정상적으로 적용되도록 구성했습니다.

# 🔐 사용자 인증

Unity와 Django 사이의 사용자 인증은
JWT 기반으로 구성했습니다.

Unity에서는 `UnityWebRequest`를 이용해
Django REST API와 통신하며,
인증이 필요한 요청에는 JWT Access Token을 Header에 포함합니다.

사용자의 인증 상태를 기반으로

- 캐릭터 정보
- 인벤토리
- 상점
- 퀘스트
- 사용자 상태

등의 데이터를 관리합니다.

# 🔧 주요 Troubleshooting

## FishNet Scene Loading 권한 문제

클라이언트에서 직접 Scene을 변경하려 했을 때
Scene Loading이 정상적으로 이루어지지 않는 문제가 발생했습니다.

FishNet의 Scene 및 Network Object 관리 권한이
서버에 있다는 점을 확인한 뒤,

`Client → ServerRpc → Server → Scene Loading`

구조로 변경했습니다.

서버의 `SceneLoadingManager`가 클라이언트의 요청을 받아
해당 Connection에 Scene을 제공하도록 구성하여 문제를 해결했습니다.

---

## Unity 프로젝트 Git 충돌

Unity Scene과 Asset을 여러 팀원이 동시에 수정하면서
Git Merge 과정에서 Scene 파일 및 `.meta` 파일 충돌이 발생했습니다.

이를 개선하기 위해

- 기능별 Branch 분리
- 담당 Scene 분리
- Merge 전 팀원 공유
- Unity 세부 버전 통일
- `.meta` 파일 변경사항 확인

등의 협업 규칙을 정해 충돌을 줄였습니다.

---

## LLM 응답 정확도 문제

LLM에게 지역 축제 관련 퀴즈와 정보를 직접 생성하도록 했을 때
존재하지 않는 장소나 검증하기 어려운 정보가 포함되는 문제가 있었습니다.

이를 개선하기 위해
검증된 데이터와 Database 검색 결과를 우선 활용하고,
LLM은 해당 결과를 기반으로 자연스러운 응답을 생성하도록 변경했습니다.

# 🎯 프로젝트 목표

UHEEVERSE는 단순히 지역 축제 정보를 보여주는 서비스가 아니라,
사용자가 직접 지역을 탐험하고 다른 사용자와 소통하며
지역 문화를 경험하는 **참여형 디지털 축제 플랫폼**을 목표로 합니다.

지역별 축제 콘텐츠를 지속적으로 추가할 수 있는 구조를 통해
지역 관광 홍보뿐만 아니라

- 관광 마케팅
- 지역 문화 교육
- 도시 브랜딩
- 지역 특산물 및 커머스

등의 분야로 확장하는 것을 목표로 합니다.
